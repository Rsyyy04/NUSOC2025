# 天线设计文档

## IFA天线设计 (2.4GHz)

### 设计参数
- **频率**: 2.4 - 2.5 GHz
- **天线类型**: Inverted-F Antenna (IFA)
- **阻抗**: 50Ω
- **增益目标**: > -2dBi

### 天线尺寸计算
```
波长 λ = c / f = 3×10^8 / 2.45×10^9 ≈ 122mm
天线长度 ≈ λ/4 ≈ 30.5mm
```

### 设计图

```
                    馈点 (Feed Point)
                         ↓
    ┌────────────────────┴────────┐
    │                              │ 
    │        主辐射臂              │ ~30mm
    │      (Main Radiator)         │
    │                              │
    │      短路点 (Short Point)    │
    └──────────┬───────────────────┘
               ↓
           GND平面
     (Ground Plane with Keepout)

尺寸参数：
- 主臂长度: 30mm
- 主臂宽度: 2mm
- 短路点位置: 距馈点 7.5mm (λ/16)
- 馈点阻抗: 通过匹配网络调整至50Ω
- Keepout区域: 天线周围5mm无铺铜
```

### 匹配网络

```
nRF52832 ──┬── C1 ── L1 ── C2 ──┬── 天线
           │                    │
          GND                  GND

参考值（需实测调整）：
C1 = 1.5pF (0402)
L1 = 3.9nH (0402)
C2 = 1.0pF (0402)

预留多组焊盘用于调试
```

### PCB设计要点

1. **天线位置**: 放置在PCB边缘
2. **Keepout区域**: 天线下方和周围无铺铜
3. **地平面**: 天线下方镂空，但保持周围有地
4. **RF走线**: 50Ω阻抗控制，最短路径

### 仿真工具
- HFSS
- CST Microwave Studio
- ADS

### 测试方法

1. **S11测试**
   - 使用矢量网络分析仪
   - 目标: S11 < -10dB @ 2.4-2.5GHz
   - VSWR < 2:1

2. **辐射测试**
   - 在暗室进行
   - 测量方向图
   - 测量增益

### 调试步骤

1. 初步仿真设计
2. PCB制作
3. S11测试，调整匹配网络
4. 辐射性能测试
5. 场景化测试（手持、遮挡等）
