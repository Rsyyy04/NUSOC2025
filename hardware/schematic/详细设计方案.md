# 智能物品防丢系统 - 硬件设计详细方案

## 一、方案总览

本方案提供完整的硬件设计实施方案，包括详细原理图、PCB布局、关键设计参数和制造文件准备。

### 1.1 设计目标
- **接收器**: 40mm × 30mm × 10mm，支持OLED显示和多标签管理
- **标签**: 25mm × 25mm × 8mm，超低功耗设计
- **通信距离**: ≥20m室内环境
- **续航**: 标签6-12个月，接收器5-7天

#### 2.2.3 RF区域设计细节

```
           天线Keepout区域
           
    ┌───────────────────────┐
    │                       │
    │  ╔═══════════════╗    │ 5mm keepout
    │  ║               ║    │
    │  ║  IFA天线      ║    │
    │  ║  30mm × 2mm   ║    │
    │  ║               ║    │
    │  ║  ┌─馈点       ║    │
    │  ║  │            ║    │
    │  ║  └─短路点     ║    │
    │  ╚═══════════════╝    │
    │                       │
    └───────────────────────┘
    
    RF走线 (50Ω阻抗):
    
    MCU ══════════ 匹配网络 ══════════ 天线
         0.3mm宽            预留调试焊盘
         5mm长

走线计算（4层板，1.6mm厚）:
- 表层走线宽度: 约0.3mm (50Ω)
- 走线与GND间距: 0.2mm
- 微带线结构

使用阻抗计算工具:
Z0 = 87/√(εr+1.41) × ln(5.98h/(0.8w+t))

其中:
εr = 4.5 (FR4介电常数)
h = 0.2mm (到GND层距离)
w = 走线宽度
t = 35μm (铜厚)
```

## 四、天线设计详细方案

### 4.1 IFA天线详细尺寸

```
              馈点位置
                 ↓
    ┌────────────┴────────────┐
    │                          │
    │    主辐射臂               │ 2mm宽
    │    30mm长                │
    │                          │
    │    ┌─ 短路点 (7.5mm)     │
    │    │                     │
    └────┴─────────────────────┘
         ↓
    ══════════════════════════
      GND平面 (keepout下方)

详细参数:
- 主臂长度: 30mm
- 主臂宽度: 2mm
- 短路点位置: 距馈点7.5mm
- 馈点阻抗: 约15-25Ω (需匹配至50Ω)
- Keepout区域: 天线周围5mm
- 地平面镂空: 35mm × 10mm
```

### 4.2 匹配网络设计

```
仿真步骤（使用HFSS/CST）:

1. 建立天线3D模型
   - PCB: 40mm×30mm×1.6mm, εr=4.5
   - 铜厚: 35μm
   - 天线几何参数如上

2. 端口设置
   - 馈点: Lumped Port, 50Ω
   - 频率范围: 2.3-2.6GHz

3. 仿真S11参数
   - 目标频率: 2.45GHz
   - 目标S11: < -10dB

4. 优化匹配网络
   - 测量天线阻抗 (Zant)
   - 计算匹配元件值
   - 使用Smith圆图设计

匹配网络计算示例:
假设天线阻抗 Zant = 20 + j30Ω

目标: 匹配到50Ω

π型网络:
C1 = 1.5pF
L1 = 3.9nH
C2 = 1.0pF

计算工具: ADS, Smith Chart
```

### 5.2 制造规格要求

```
PCB参数:
- 板材: FR4, Tg>150°C
- 层数: 4层 (接收器), 2层或4层 (标签)
- 板厚: 1.6mm ±0.1mm
- 铜厚: 1oz (35μm)
- 最小线宽/线距: 6/6 mil (0.15mm)
- 最小过孔: 0.3mm孔径
- 表面处理: ENIG (沉金) 或 HASL (喷锡)
- 阻焊颜色: 绿色/黑色

特殊要求:
- RF区域阻抗控制
- 天线区域严格Keepout
- 最终检验: 电性能测试+飞针测试
```

## 六、组装与调试

### 6.1 组装顺序

```
接收器组装:
1. 贴片元件焊接
   ① 电阻、电容（0402/0805）
   ② MCU（nRF52832, QFN48）
   ③ LDO、充电IC等
   ④ LED、晶振

2. 插件元件
   ① 按键开关
   ② USB接口
   ③ SWD插座
   ④ 电池连接器

3. OLED模块
   ① 插针焊接或排针连接

工具要求:
- 恒温烙铁 (300-350°C)
- 热风枪 (QFN封装)
- 镊子、放大镜
- 助焊剂
```

### 6.2 硬件调试步骤

```
第一步: 电源测试
□ 上电前检查：短路检测
□ 电池接入，测量VDD = 3.3V ±0.1V
□ 各测试点电压正常
□ 电流消耗 < 100μA（上电待机）

第二步: MCU测试
□ 连接J-Link调试器
□ 识别nRF52832芯片
□ 读取芯片ID
□ 烧录测试程序（LED闪烁）

第三步: RF测试
□ 测量天线S11参数
□ 调整匹配网络
□ 发射功率测试 (0dBm)
□ 接收灵敏度测试

第四步: 外设测试
□ 按键响应测试
□ OLED显示测试
□ 蜂鸣器声音测试
□ LED指示测试

第五步: BLE功能测试
□ 广播测试
□ 连接测试
□ 数据传输测试
□ RSSI读取测试
```

## 七、总结与建议

### 7.1 设计优势
1. ✅ 完整的原理图和PCB设计方案
2. ✅ 详细的元器件选型和BOM
3. ✅ 专业的RF天线设计
4. ✅ 可制造性设计（DFM）

### 7.2 实施建议
1. **原型阶段**: 先制作2-3套原型，验证设计
2. **小批量**: 验证通过后，制作10-20套进行测试
3. **批量生产**: 测试稳定后，批量生产
4. **迭代优化**: 根据测试结果优化设计

### 7.3 时间计划
```
Week 1-2: 原理图设计和审核
Week 3-4: PCB设计和审核
Week 5: PCB制作（5-7天）

```
