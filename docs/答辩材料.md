# 智能物品防丢系统 - 答辩材料

## 一、项目概述 (2分钟)

### 1.1 项目背景
在日常生活中，人们经常会遗失钥匙、钱包等重要物品。我们设计了一个基于BLE的智能防丢系统来解决这一痛点。

### 1.2 系统组成
- **接收器（主机）**: 随身携带的监控设备
- **标签（从机）**: 附着在重要物品上的追踪器

### 1.3 核心创新点
1. **2秒快速报警**: 检测到断线后2秒内响应
2. **智能寻找**: 基于RSSI导航，快速定位丢失物品
3. **超低功耗**: 标签续航6-12个月
4. **板载天线**: 自主设计IFA天线，小型化集成

## 二、系统设计 (5分钟)

### 2.1 硬件架构

#### 接收器硬件
```
核心: nRF52832 MCU
显示: 0.96" OLED (128x64)
提示: 蜂鸣器 + LED
电源: 300mAh锂电池 + TP4056充电
尺寸: 40×30×10mm
```

#### 标签硬件
```
核心: nRF52832 MCU
提示: 蜂鸣器/振动马达
交互: 单按键（单击/双击）
电源: CR2032纽扣电池
尺寸: 25×25×8mm
```

### 2.2 软件架构

#### 接收器软件
- **BLE Central**: 支持最多8个标签
- **标签管理**: 配对、解绑、重命名
- **连接监测**: 500ms RSSI检测周期
- **报警系统**: 多种报警模式
- **OLED界面**: 直观的菜单系统

#### 标签软件
- **BLE Peripheral**: 广播与连接
- **按键检测**: 单击/双击识别
- **低功耗**: 待机3μA

### 2.3 通信协议

#### GATT服务设计
```
防丢服务 (UUID: 0xABCD)
├─ 连接状态 (Read, Notify)
├─ RSSI值 (Read, Notify)
├─ 寻找命令 (Write)
├─ 配置参数 (Read, Write)
├─ 断线记录 (Read)
└─ 标签名称 (Read, Write)
```

#### 连接参数
- 连接间隔: 100-200ms
- RSSI监测: 500ms周期
- 报警阈值: -75dBm (可调)

## 八、Q&A准备

### 8.1 技术问题

**Q: 为什么选择nRF52832？**
A: 
- 集成BLE 5.0，成熟的协议栈
- 超低功耗，适合电池供电
- 丰富的SDK和开发资源
- 性价比高

**Q: 如何保证2秒内报警响应？**
A:
- 连接间隔100-200ms
- RSSI检测周期500ms
- 无从机延迟
- 高优先级报警任务

**Q: 标签如何达到6-12个月续航？**
A:
- 待机功耗仅3μA
- 广播间隔1秒（可调）
- 连接后优化参数
- 动态电源管理

**Q: 天线设计的难点是什么？**
A:
- 小尺寸与性能平衡
- 周围金属的影响
- 手握持的频偏
- 匹配网络调试

### 8.2 应用问题

**Q: 如何防止误报警？**
A:
- 可调RSSI阈值
- 多次确认机制
- 临时禁用功能
- 智能学习环境

**Q: 能否防止恶意攻击？**
A:
- BLE配对绑定
- AES-128加密
- 白名单机制
- 连接认证

**Q: 系统成本如何？**
A:
- 接收器: ~110元
- 标签: ~60元
- 批量可降低30%
