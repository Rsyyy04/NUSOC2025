# 智能物品防丢系统设计文档

## 一、项目概述

本项目旨在设计一个基于 BLE (Bluetooth Low Energy) 的智能物品防丢系统，由一个接收器（主机）和多个标签发射器（从机）组成。系统能够实现快速配对、连接监测、防丢报警、寻找模式等功能，同时保证长续航和小型化设计。

### 1.1 系统组成
- **接收器（主机）**：可放置于背包或随身佩戴
- **标签（从机）**：可挂载于钥匙、钱包等物品

### 1.2 核心功能
1. 快速配对与解绑
2. 多标签连接管理
3. 实时连接监测
4. 断线报警（2秒内响应）
5. 寻找模式
6. 低功耗设计

## 二、硬件设计方案

### 2.1 MCU选型

#### 方案A：nRF52系列
- **推荐型号**：nRF52832 / nRF52840
- **优势**：
  - 集成BLE 5.0协议栈
  - 超低功耗（3.5μA @ System OFF）
  - 内置2.4GHz射频收发器
  - 丰富的GPIO和外设
  - 成熟的SDK和工具链

#### 方案B：ESP32系列
- **推荐型号**：ESP32-C3 / ESP32-S3
- **优势**：
  - 支持BLE 5.0
  - 集成WiFi（可用于上位机通信）
  - 性价比高
  - 丰富的开发资源

**推荐方案：nRF52832**（功耗更低，更适合电池供电场景）

### 2.3 关键外设选型

#### 2.3.1 电源系统
- **电池**：CR2032纽扣电池（标签）/ 300mAh锂电池（接收器）
- **充电IC**：TP4056（接收器，可选标签）
- **LDO**：XC6220（超低功耗，Iq < 1μA）
- **电池保护**：DW01A + FS8205A

#### 2.3.2 提示设备
- **蜂鸣器**：无源蜂鸣器（3.3V，85dB）
- **振动马达**：0820型扁平振动马达（3.3V，60mA）
- **LED**：0603贴片LED（红色/绿色/蓝色）

#### 2.3.3 显示屏（接收器）
- **OLED**：0.96寸 128x64 I2C/SPI接口
- **驱动IC**：SSD1306

#### 2.3.4 按键
- **轻触开关**：6x6mm贴片轻触开关
- **功能**：
  - 接收器：菜单导航、确认、返回
  - 标签：单击启用/双击禁用报警

### 2.4 PCB设计要求

#### 2.4.1 尺寸规格
- **接收器**：≤ 40mm x 30mm x 10mm
- **标签**：≤ 25mm x 25mm x 8mm

#### 2.4.2 PCB层数
- **推荐**：4层板
  - Layer 1: 信号层（射频走线、组件焊盘）
  - Layer 2: GND层（完整地平面）
  - Layer 3: 电源层（3.3V）
  - Layer 4: 信号层（辅助走线）

#### 2.4.3 射频设计关键点
1. **天线布局**
   - 远离金属件和高频干扰源
   - 天线下方保持镂空（无铺铜）
   - 预留天线调试焊盘

2. **RF走线**
   - 50Ω阻抗匹配
   - 最短路径连接
   - 避免直角拐角

3. **接地**
   - 射频地单点接地
   - GND过孔密布（λ/20间距）

### 2.5 天线设计方案

#### 方案1：板载IFA天线（推荐）
- **类型**：Inverted-F Antenna
- **优势**：小型化、成本低、集成度高
- **设计参数**：
  - 谐振频率：2.4GHz
  - 天线长度：约30mm
  - 馈点位置：距短路点约λ/4

#### 方案2：陶瓷贴片天线
- **型号**：2450AT18A100（Johanson Technology）
- **优势**：性能稳定、尺寸小（2.5x2.0mm）
- **应用**：空间极度受限场景

#### 方案3：外置弹簧天线
- **优势**：性能最佳、易调试
- **劣势**：占用空间大

**推荐方案：板载IFA天线**（性能与尺寸平衡）

### 3.3 BLE通信协议设计

#### 3.3.1 广播数据格式（标签）
```
广播数据包结构：
┌─────────────────────────────────────────┐
│  Field          │  Length  │  Value     │
├─────────────────────────────────────────┤
│  Flags          │  3 bytes │  0x02 0x01 0x06  │
│  Device Name    │  Variable│  "AntiLoss_Tag_XX" │
│  Service UUID   │  3 bytes │  0x03 0x03 0xABCD  │
│  Manufacturer   │  Variable│  自定义数据         │
│    - Company ID │  2 bytes │  0xFFFF             │
│    - Battery    │  1 byte  │  0-100%             │
│    - Status     │  1 byte  │  Bit flags          │
└─────────────────────────────────────────┘
```

#### 3.3.2 自定义GATT服务

**防丢服务 (Anti-Loss Service)**
- **UUID**: 0x180F (自定义)

| 特征值 | UUID | 属性 | 描述 |
|--------|------|------|------|
| 连接状态 | 0x2A00 | Read, Notify | 标签连接状态 |
| RSSI值 | 0x2A01 | Read, Notify | 信号强度 |
| 寻找命令 | 0x2A02 | Write | 触发标签蜂鸣/振动 |
| 配置 | 0x2A03 | Read, Write | 报警阈值等配置 |
| 断线记录 | 0x2A04 | Read | 断线时间戳历史 |
| 标签名称 | 0x2A05 | Read, Write | 自定义标签名称 |

### 3.4 核心功能实现

#### 3.4.1 配对与管理流程
```
接收器（主机）配对流程：
1. 进入配对模式
2. 开始BLE扫描
3. 过滤目标设备（设备名称/UUID）
4. 发起连接请求
5. 连接成功后进行服务发现
6. 订阅RSSI通知
7. 保存标签信息到Flash
8. 更新显示列表

标签（从机）配对流程：
1. 进入配对模式（按键触发）
2. 开始快速广播（100ms间隔）
3. 等待连接请求
4. 连接建立后协商参数
5. 保存主机信息
6. LED指示配对成功
```

#### 3.4.2 连接监测与报警
```c
// 伪代码
void connection_monitor_task(void) {
    for (each_tag in tag_list) {
        if (tag.connected) {
            // 读取RSSI
            int8_t rssi = get_rssi(tag.conn_handle);
            tag.rssi = rssi;
            
            // 检查RSSI阈值
            if (rssi < RSSI_THRESHOLD) {
                if (!tag.warning_state) {
                    tag.warning_state = true;
                    tag.warning_timestamp = get_timestamp();
                    trigger_alarm();  // 2秒内响应
                }
            } else {
                tag.warning_state = false;
            }
        } else {
            // 连接断开
            if (!tag.disconnect_alarmed) {
                tag.disconnect_timestamp = get_timestamp();
                save_disconnect_record(tag);
                trigger_alarm();
                tag.disconnect_alarmed = true;
            }
        }
    }
}
```

#### 3.4.3 寻找模式实现
```c
// 寻找模式状态机
typedef enum {
    SEARCH_IDLE,
    SEARCH_SCANNING,
    SEARCH_APPROACHING,
    SEARCH_FOUND
} search_state_t;

void search_mode_handler(tag_info_t *target_tag) {
    static search_state_t state = SEARCH_IDLE;
    static int8_t last_rssi = -100;
    
    switch (state) {
        case SEARCH_IDLE:
            // 进入寻找模式
            send_find_command(target_tag);  // 让标签蜂鸣
            state = SEARCH_SCANNING;
            break;
            
        case SEARCH_SCANNING:
            current_rssi = get_rssi(target_tag);
            if (current_rssi > last_rssi + 5) {
                // RSSI增强，正在接近
                state = SEARCH_APPROACHING;
                beep_short();  // 短促提示音
            }
            last_rssi = current_rssi;
            break;
            
        case SEARCH_APPROACHING:
            current_rssi = get_rssi(target_tag);
            if (current_rssi > -50) {
                // 非常接近
                state = SEARCH_FOUND;
                beep_long();  // 长提示音
                led_blink_fast();
            }
            break;
            
        case SEARCH_FOUND:
            // 找到标签，退出寻找模式
            stop_find_command(target_tag);
            state = SEARCH_IDLE;
            break;
    }
}
```

### 3.5 低功耗设计

#### 3.5.1 功耗优化策略
1. **动态电源管理**
   - 空闲时进入System OFF模式
   - 使用RTC唤醒
   - 关闭未使用外设

2. **BLE参数优化**
   - 连接间隔：100-200ms
   - 广播间隔：标签1s，接收器按需
   - 使用连接事件长度限制

3. **外设优化**
   - OLED显示超时关闭
   - LED使用低占空比PWM
   - 蜂鸣器短暂激活

#### 3.5.2 典型功耗分析
```
标签功耗：
- 广播状态：50μA @ 1s间隔
- 连接状态：150μA @ 200ms间隔
- 深度睡眠：3μA
- 蜂鸣响应：15mA @ 2s

接收器功耗：
- 多连接监测：500μA
- OLED显示：8mA
- 报警：20mA @ 3s
- 待机：50μA

预计续航：
- 标签（CR2032 220mAh）：6-12个月
- 接收器（300mAh锂电）：5-7天（正常使用）
```
