# 智能物品防丢系统 - 硬件设计规范

## 一、设计概述

本文档详细说明智能物品防丢系统的硬件设计规范，包括原理图设计、PCB布局、元器件选型等内容。

## 二、原理图设计

### 2.1 接收器（主机）原理图

#### 2.1.1 主控MCU电路
```
nRF52832 核心电路：
- MCU: nRF52832-QFAA (QFN48封装)
- 晶振: 32MHz主晶振 + 32.768kHz RTC晶振
- 复位: 外部复位按键 + RC复位电路
- 调试: SWD接口（SWDIO, SWCLK）
- 去耦电容: 100nF x 4 + 10μF x 1 (电源去耦)
```

#### 2.1.2 射频电路
```
RF匹配网络：
- π型匹配网络
- 预留多组电容电感焊盘
- 50Ω阻抗匹配至天线
- ESD保护（可选）

天线：
- 板载IFA天线 或
- U.FL座子连接外部天线
```

#### 2.1.3 电源管理电路
```
电池供电系统：
- 锂电池: 3.7V 300mAh
- 充电IC: TP4056（1A充电电流）
- 电池保护: DW01A + FS8205A
- LDO: XC6220B331（3.3V输出）
- 电量检测: ADC采样分压电路
```

#### 2.1.4 外设接口
```
OLED显示屏（I2C）：
- SDA, SCL
- VCC: 3.3V
- 上拉电阻: 4.7kΩ

按键接口：
- UP, DOWN, LEFT, RIGHT, OK, BACK
- 上拉 + 去抖电容

蜂鸣器/马达驱动：
- N-MOS驱动（2N7002）
- PWM控制
- 反向二极管保护

LED指示灯：
- GPIO直驱 + 限流电阻
- 红/绿/蓝三色LED
```

### 2.2 标签（从机）原理图

#### 2.2.1 主控MCU电路
```
与接收器相同的MCU核心电路
```

#### 2.2.2 射频电路
```
与接收器相同的RF电路
```

#### 2.2.3 电源管理电路
```
纽扣电池供电：
- 电池: CR2032 (3V 220mAh)
- LDO: 超低功耗LDO（可选，直接供电也可）
- 电量检测: ADC采样
```

#### 2.2.4 外设接口
```
按键：
- 单个轻触开关
- 支持单击/双击检测

蜂鸣器：
- 无源蜂鸣器 + N-MOS驱动
- PWM频率控制

振动马达（可选）：
- 0820扁平马达
- N-MOS驱动

LED：
- 单色LED + 限流电阻
```

## 四、PCB设计规范

### 4.1 PCB层叠结构（4层板）

```
Layer 1 (Top):      信号层 - 组件、RF走线
Layer 2 (Inner1):   GND层 - 完整接地平面
Layer 3 (Inner2):   电源层 - 3.3V电源平面
Layer 4 (Bottom):   信号层 - 辅助走线、备用焊盘
```

### 4.2 设计规则

#### 4.2.1 走线规则
- 信号线宽：0.15mm（最小）
- 电源线宽：0.3mm（3.3V）/ 0.4mm（VBAT）
- RF走线：计算50Ω阻抗（通常0.3-0.5mm，取决于板厚）
- 线间距：0.15mm（最小）
- 过孔：0.3mm孔径 / 0.5mm焊盘

#### 4.2.2 铺铜规则
- GND铺铜：完整铺铜，无碎铜
- 电源铺铜：避开RF区域
- 热焊盘：十字连接
- 过孔：λ/20间距（2.4GHz约6mm）

### 4.3 RF设计要点

#### 4.3.1 天线设计
```
IFA天线参数（2.4GHz）：
- 天线长度: ~30mm
- 天线宽度: 2mm
- 馈点位置: 距短路点约λ/4
- 天线clearance: 周围5mm无铺铜
- 地平面: 天线下方镂空

匹配网络：
- π型匹配: C - L - C
- 预留多组0402焊盘
- 参考值: 1.5pF - 3.9nH - 1pF
```

#### 4.3.2 RF走线
```
要求：
- 50Ω阻抗匹配
- 最短路径（< 20mm）
- 避免直角，使用圆角或45°拐角
- 远离数字信号线
- 两侧GND Guard隔离
```

### 4.5 关键注意事项

1. **EMC设计**
   - 所有电源引脚近端去耦
   - 晶振走线短而粗，远离干扰源
   - 敏感信号远离开关电源

2. **热设计**
   - 功率器件加大铺铜散热
   - 充电IC下方加散热过孔

3. **机械设计**
   - 预留安装孔
   - 定位标记
   - 极性标识

## 五、天线设计详细说明

### 5.1 IFA天线设计

#### 5.1.1 设计步骤
1. 确定天线类型：Inverted-F Antenna
2. 计算天线长度：λ/4 ≈ 31mm @ 2.4GHz
3. 设计匹配网络：调整至50Ω
4. 仿真优化：HFSS/CST仿真
5. 实物调试：网络分析仪测试

#### 5.1.2 参考设计
```
        馈点
         ↓
    ┌────┴────┐
    │         │ 30mm
    │    短路点│
    └─────────┘
         ↓
       GND平面

参数：
- 主臂长度: 30mm
- 主臂宽度: 2mm
- 短路点位置: 距馈点7.5mm
- 馈点阻抗: 通过匹配网络调整至50Ω
```

### 5.2 天线测试规范

#### 5.2.1 S11测试
- 目标: S11 < -10dB @ 2400-2500MHz
- 工具: 矢量网络分析仪
- 方法: 近场测试 + 校准

#### 5.2.2 辐射测试
- 发射功率测试
- 方向图测试
- 效率测试

## 六、制造文件输出

### 6.1 Gerber文件清单
- Top Layer (GTL)
- Bottom Layer (GBL)
- Top Solder Mask (GTS)
- Bottom Solder Mask (GBS)
- Top Silkscreen (GTO)
- Bottom Silkscreen (GBO)
- Drill File (TXT)
- Board Outline (GKO)

### 6.2 制造要求
- 板厚: 1.6mm
- 铜厚: 1oz (35μm)
- 最小线宽/线距: 6/6 mil
- 最小过孔: 0.3mm
- 表面处理: ENIG（沉金）或 HASL（喷锡）
- 阻焊颜色: 绿色/黑色
- 字符颜色: 白色
