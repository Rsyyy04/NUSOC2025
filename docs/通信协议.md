# 智能物品防丢系统 - 通信协议规范

## 一、协议概述

本文档定义智能物品防丢系统中接收器（主机）和标签（从机）之间的BLE通信协议。

### 1.1 协议栈
- **物理层**: 2.4GHz ISM频段
- **链路层**: BLE 5.0
- **应用层**: GATT (Generic Attribute Profile)

### 1.2 角色定义
- **接收器**: BLE Central（中心设备）
- **标签**: BLE Peripheral（外设）

## 二、广播数据格式

### 2.1 标签广播数据

#### 2.1.1 广播包结构
```
┌─────────────────────────────────────────────────┐
│  AD Type  │  Length │  Data                     │
├─────────────────────────────────────────────────┤
│  Flags    │  0x02   │  0x01 0x06                │
│  Complete │  0x0D   │  "AntiLoss_Tag_XX"        │
│  Name     │         │                           │
│  Complete │  0x03   │  0x03 0xCD 0xAB           │
│  Service  │         │  (0xABCD)                 │
│  UUID16   │         │                           │
│  Mfg Data │  0x07   │  0xFF 0xFF [Battery]      │
│           │         │  [Status] [Reserved]      │
└─────────────────────────────────────────────────┘
```

#### 2.1.2 制造商数据格式
```
Offset  Length  Description
0-1     2       Company ID (0xFFFF)
2       1       Battery Level (0-100%)
3       1       Status Flags
                Bit 0: Alarm Enabled
                Bit 1: Find Mode
                Bit 2-7: Reserved
4-5     2       Reserved
```

### 2.2 广播参数
```c
#define ADV_INTERVAL_FAST   MSEC_TO_UNITS(100, UNIT_0_625_MS)   // 配对模式
#define ADV_INTERVAL_SLOW   MSEC_TO_UNITS(1000, UNIT_0_625_MS)  // 正常模式
#define ADV_DURATION        0  // 持续广播
```

## 三、GATT服务定义

### 3.1 防丢服务 (Anti-Loss Service)

#### 3.1.1 服务UUID
```
Service UUID: 0xABCD (16-bit自定义)
或
Service UUID: 0x0000ABCD-0000-1000-8000-00805F9B34FB (128-bit)
```

#### 3.1.2 特征值定义

| 特征值名称 | UUID | 属性 | 数据类型 | 长度 | 描述 |
|-----------|------|------|---------|------|------|
| Connection Status | 0x2B00 | Read, Notify | uint8 | 1 | 连接状态 |
| RSSI Value | 0x2B01 | Read, Notify | int8 | 1 | 信号强度 |
| Find Command | 0x2B02 | Write | uint8 | 1 | 寻找命令 |
| Configuration | 0x2B03 | Read, Write | struct | 4 | 配置参数 |
| Disconnect Log | 0x2B04 | Read | struct | Variable | 断线记录 |
| Tag Name | 0x2B05 | Read, Write | string | 16 | 标签名称 |
| Battery Level | 0x2A19 | Read, Notify | uint8 | 1 | 电池电量 |
| Alarm Enable | 0x2B06 | Read, Write | uint8 | 1 | 报警开关 |

### 3.2 特征值详细说明

#### 3.2.1 Connection Status (0x2B00)
```c
typedef enum {
    CONN_STATUS_DISCONNECTED = 0,
    CONN_STATUS_CONNECTING   = 1,
    CONN_STATUS_CONNECTED    = 2,
    CONN_STATUS_BONDED       = 3
} conn_status_t;

// 读取：获取当前连接状态
// 通知：连接状态变化时自动通知
```

#### 3.2.2 RSSI Value (0x2B01)
```c
typedef int8_t rssi_value_t;  // -127 to 20 dBm

// 读取：获取当前RSSI值
// 通知：RSSI变化超过5dBm时通知（可配置）
```

#### 3.2.3 Find Command (0x2B02)
```c
typedef enum {
    FIND_CMD_STOP  = 0,  // 停止寻找
    FIND_CMD_START = 1   // 开始寻找
} find_command_t;

// 写入：控制标签进入/退出寻找模式
// 标签收到START命令后开始蜂鸣/振动
```

#### 3.2.4 Configuration (0x2B03)
```c
typedef struct {
    int8_t  rssi_threshold;     // RSSI报警阈值 (-127 to 0)
    uint8_t rssi_notify_delta;  // RSSI通知变化量 (0-20 dBm)
    uint8_t alarm_enabled;      // 报警启用标志 (0/1)
    uint8_t reserved;           // 保留
} tag_config_t;

// 读取：获取当前配置
// 写入：修改配置参数
```

#### 3.2.5 Disconnect Log (0x2B04)
```c
#define MAX_LOG_ENTRIES 10

typedef struct {
    uint32_t timestamp;     // Unix时间戳
    int8_t   last_rssi;     // 断开前最后的RSSI
    uint8_t  reason;        // 断开原因
    uint8_t  reserved;      // 保留
} disconnect_log_entry_t;

typedef struct {
    uint8_t count;          // 记录数量
    disconnect_log_entry_t entries[MAX_LOG_ENTRIES];
} disconnect_log_t;

// 读取：获取断线历史记录（最多10条）
```

#### 3.2.6 Tag Name (0x2B05)
```c
typedef char tag_name_t[16];  // UTF-8字符串，以NULL结尾

// 读取：获取标签名称
// 写入：修改标签名称（最长15字符 + NULL）
```

#### 3.2.7 Battery Level (0x2A19)
```c
typedef uint8_t battery_level_t;  // 0-100%

// 读取：获取电池电量
```

#### 3.2.8 Alarm Enable (0x2B06)

## 四、连接参数

### 4.1 推荐连接参数
```c
// 连接间隔
#define MIN_CONN_INTERVAL   MSEC_TO_UNITS(100, UNIT_1_25_MS)  // 100ms
#define MAX_CONN_INTERVAL   MSEC_TO_UNITS(200, UNIT_1_25_MS)  // 200ms

// 从机延迟
#define SLAVE_LATENCY       0  // 无延迟，确保实时性

// 监督超时
#define CONN_SUP_TIMEOUT    MSEC_TO_UNITS(4000, UNIT_10_MS)   // 4s
```

### 4.2 连接间隔说明
- **100-200ms**: 平衡功耗和响应速度
- **无从机延迟**: 保证2秒内报警响应
- **4s超时**: 快速检测断线

## 五、安全机制

### 5.1 配对与绑定

#### 5.1.1 配对方式
- **Just Works**: 简单配对（默认）
- **可选**: Passkey Entry（更高安全性）

#### 5.1.2 绑定流程
```
1. 接收器发起连接
2. 标签请求配对
3. 执行配对过程
4. 交换并保存密钥
5. 建立加密连接
```

### 5.2 白名单
```c
// 标签维护白名单，只接受已配对接收器的连接
#define MAX_BONDED_DEVICES  1  // 标签只绑定一个接收器
```

## 六、通信流程

### 6.1 配对流程

```
接收器                          标签
  │                              │
  │──── Scan ──────────────────> │
  │                              │ (广播中)
  │<─── Adv Report ────────────  │
  │                              │
  │──── Connect Request ───────> │
  │                              │
  │<─── Connected ──────────────  │
  │                              │
  │──── Service Discovery ─────> │
  │                              │
  │<─── Services Info ──────────  │
  │                              │
  │──── Enable Notify ─────────> │
  │                              │
  │──── Write Tag Name ────────> │
  │                              │
  │<─── Write Success ──────────  │
  │                              │
  │──── Save to Flash ──────────  │
  │                              │
```

### 6.2 连接监测流程

```
接收器                          标签
  │                              │
  │──── Read RSSI ────────────> │
  │                              │
  │<─── RSSI Value ─────────────  │
  │                              │
  │  (检查RSSI阈值)              │
  │                              │
  │  if (RSSI < Threshold)       │
  │  ├── 触发报警                │
  │  └── 记录事件                │
  │                              │
```

### 6.3 寻找模式流程

```
接收器                          标签
  │                              │
  │  (用户选择"寻找标签")        │
  │                              │
  │──── Write Find Cmd (1) ────> │
  │                              │
  │<─── Write Success ──────────  │
  │                              │ (开始蜂鸣)
  │                              │
  │──── Read RSSI ────────────> │
  │                              │
  │  (RSSI增强，接近中...)       │
  │  ├── 短促提示音              │
  │                              │
  │  (RSSI > -50dBm, 找到!)      │
  │  ├── 长提示音                │
  │  └── LED闪烁                 │
  │                              │
  │──── Write Find Cmd (0) ────> │
  │                              │
  │                              │ (停止蜂鸣)
```

### 6.4 断线处理流程

```
接收器                          标签
  │                              │
  │<─── Disconnected ───────────  │
  │                              │
  │  (检测到断线)                │
  │  ├── 获取时间戳              │
  │  ├── 触发报警                │
  │  └── 保存断线记录            │
  │                              │
  │──── Start Scan ─────────────  │ (重新广播)
  │                              │
  │  (尝试重连)                  │
  │                              │
```

## 七、错误处理

### 7.1 错误码定义
```c
typedef enum {
    ERR_SUCCESS         = 0x00,
    ERR_INVALID_PARAM   = 0x01,
    ERR_NOT_SUPPORTED   = 0x02,
    ERR_NOT_CONNECTED   = 0x03,
    ERR_BUSY            = 0x04,
    ERR_TIMEOUT         = 0x05,
    ERR_STORAGE_FULL    = 0x06,
    ERR_UNKNOWN         = 0xFF
} error_code_t;
```

### 7.2 错误响应
- GATT写入失败时返回相应错误码
- 接收器收到错误后重试或提示用户

## 八、性能指标

### 8.1 延迟指标
- **连接建立**: < 1秒
- **RSSI读取**: < 100ms
- **寻找命令响应**: < 200ms
- **报警触发**: < 2秒

### 8.2 可靠性指标
- **连接稳定性**: > 99% (10m范围内)
- **RSSI精度**: ±5dBm
- **数据完整性**: CRC校验
